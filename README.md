2×2 MIMO BER Simulation using MATLAB Simulink
• Designed and simulated a 2×2 MIMO wireless communication system with BPSK modulation.
• Implemented Rayleigh fading, AWGN channel, and BER analysis.
• Technologies: MATLAB R2025b, Simulink, Communications Toolbox.

This project estimates the Bit Error Rate (BER) of a Multiple-Input-Multiple-Output (MIMO) channel. The MIMO channel has been made using double Single-Input-Single-Output (SISO) channels. White Gaussian Noise has been added to the input signals to introduce error into the channels and then analyse it.
